# 多标签分类和多标签学习
多标签学习，MLL（multi-label learning）。包括两个主要任务：多标签分类(MLC)和标签排序(LR)。更进一步还有多标签排序，可以理解为MLC和LR的泛化，它同时产生一个二元划分和一致性(consistent)排序。

**一个同属于监督学习，并和多标签分类很相关的问题就是排序问题（ranking）**。排序任务是对一个标签集排序，使得排在前面的标签与相应实例更相关。

在特定分类问题中，标签属于一个层次结构（hierarchical structure）。当数据集标签属于一个层次结构的时候，我们这个任务为层次分类，如果一个样本与层次结构的多个节点相关， 那么这个任务就被称为层次多标签分类。

多标签 VS 多类：有多个类别，但只能将每个实例划分到一个类别，那么这种问题就是我们所说的多类分类问题。将每个实例分类到多个种类，那么这种类型的问题就是我们说的多标签分类问题。
预测非互斥分类的任务。

多实例学习（multiple-instance learning）是监督学习的一个变种，用的比较少 ，就不说了。

## 趋势
对多标签识别的研究主要集中在标签间的语义关系、对象proposal（利用图像中局部目标的信息）和注意力机制

## 可能遇到的难点
1）标签数量不确定，有些样本可能只有一个标签，有些样本的标签可能高达几十甚至上百个，使得这特征空间过大。

2）标签之间有着相互依赖，如何利用这种结构化的语义信息是难点。例如一张鸟类的图片，一般不会只有鸟类一个物体，可能还会有云朵、太阳、树林（这里已经隐含一种我们认为的相关性了，即鸟类和天空相关）。
与单标签分类相比，多标签分类的输出空间呈现指数级增长，那么目前对于Multi-Label的这类特性，学界一般是集中在更好的分析Label之间的相关性，就可以避免这种指数增长。

3）分类数据量及其不均衡
一方面，某个类别的对应样例可能远多于另一个类别，这是类别之间不平衡(interclass)；某个类别对应的正样本可能远多于负样本，这是类别之内不平衡(innerclass)。另一方面，从标签集合角度看，有的标签集合的样本相对多，有的相对少。
可以使用上采样方法为稀有类生成人造样本，从而让模型关注稀有类。为了在多标签场景下创建新样本，我们可以使用多标签合成少数类过采样技术（MLSMOTE）。过采样，损失函数权重，数据增强，focal loss。


4）每类标签分类难度也各不相同


## 依据解决问题的角度分类
1）基于问题转化（Problem Transformation）的方法。
将多标签问题转换为单标签问题，使之适用现有算法。
代表性学习算法Binary Relevance（二元关联），Classifier Chains（分类器链），LP（Label Powerset），Calibrated Label Ranking， Random k-labelsets。总体来说，这类方法有考虑标签之间的联系，但是对于标签较多、数据量较大的数据集，这类方法的计算复杂度是一个很明显的缺陷。

Binary Relevance（二元关联）：就是将每个标签看作一个单独的二分类问题。优点是简单；缺点是因为它是单独处理每个目标变量，所以压根没有考虑标签之间的关联。
Classifier Chains（分类器链）：第一个分类器只用输入数据训练，然后在输入空间以及链条上前面所有分类器上训练接下来的每个分类器。和Binary Relevance非常相似，唯一的区别是它是按顺序组成链条以保存标签之间的关联。
LP（Label Powerset）：遍历训练数据中的所有标签组合，则每一个实例都只有唯一标签，训练的就变成了多类分类器。

2）基于算法适应的方法和算法适应方法（Algorithm Adaptation）。
基于算法适应的方法是指针对某一特定的算法进行扩展，从而能够直接处理多标签数据，改进算法，适应数据。问题转化方法是将多标签问题转化成一个或者多个单标签问题，而算法适应方法是在多标签的基础上研究算法。
近年来，用于多标签的算法适应的算法越来越多，代表性学习算法ML-kNN，Rank-SVM，LEAD，CML。
这类方法有考虑标签之间的联系，但是对于标签较多、数据量较大的数据集，这类方法的计算复杂度是一个很明显的缺陷。

## 对于分类策略，基于考察标签之间相关性的不同方式
1）First-Order Strategy（一阶策略）: 考虑的是label之间相互独立，那么就可以把Multi-label问题转换为普通的分类问题。如果一个Label有多类的话，那么就用传统的One vs All来解决。

Binary Relevance：该类策略通过逐一考察单个标签而忽略标签之间的相关性，如将多标签学习问题分解为个独立的二类分类问题，从而构造多标签学习系统。该类方法效率较高且实现简单，但由于其完全忽略标签之间可能存在的相关性，其系统的泛化性能往往较低。

2）Second-Order Strategy: 这一类是考虑Label之间的两两相关性，结果会导致计算复杂度有显著的增加。

3）High-Order Strategy: 这个就是考虑多Label之间的相关性，计算复杂度会更高。

## 深度学习中的具体算法
1）DNN + Softmax
label弄成向量如[0 1 0 1 0 0 1]，Loss Function是CE的话，做加和(/sum(label))就行（即将label从one-hot改成multi-hot），Softmax求导里面有一个点乘label，所以参数矩阵W迭代会更新到对应W的行(或列)上面–完全的Deep Learning套路，这其实就是Hinton的《Distilling the Knowledge in a Neural Network 》中提的 the soft targets。

2）DNN + Sigmoid，Multi-dimension Logistic Regression
训练过程和1）差不多，与Softmax的差别在于训练过程最后层概率不做Normalization。

3）在softmax层之前加入一个coding层，每一种分类用一个bit位表示。
coding层具体是用sigmoid激活函数，阈值设为0.5.如果值大于0.5，则属于此标签，小于0.5，则不属于这个标签。

4）Classifier Chains，把原问题分解成有先后顺序的一系列Binary Classification，然后前边的Binary Classification会对后边的产生影响；

5）Calibrated label ranking，这个有点像Multi-Classification中One vs One的策略，就是通过两两对比，然后进行投票决定分类效果。

6）ASL loss，一种基于focal loss改进的非对称loss，不仅具备focal loss进行正负样本平衡的作用，还具备减少容易负样本loss贡献的效果。
虽然ASL loss的落脚点是多标签分类，但是ASL loss不仅可以应用于多标签分类，还可以应用于单标签分类任务，物体检测任务。对缓解长尾（long-tail）数据分布具有很好的效果。

## 评价指标
主要有平均每级精度(CP)、召回率(CR)、F1 (CF1)和平均总体精度(OP)、召回率(OR)、F1 (OF1)。一般来说，总体平均F1 (OF1)、每个类平均F1 (CF1)和mAP对于性能评估更重要。
对于每一幅图像，如果标签的置信度大于0.5，则被预测为正。一般为了公平比较，会使用前n个标签的结果。


# 论外（与无监督学习的关系）
弱监督学习的目的，与监督学习一致，然而其获得的样本并没有完整的标签。从标签缺失的形式和处理方式的不同，又可以分为半监督学习、主动学习、多示例学习／多标签学习、和强化学习。

1）半监督学习中，只有少量的样本具有标签；
2）主动学习中，机器可以询问真实的标签，但需要考虑询问的代价；
3）多示例学习中，一个对象表示为一组样本的包，而标签只在包的层面上，在样本的层面上却没有标签；
4）多标签学习中，一个样本对应一组标签，因此需要处理巨大的标签组合空间问题；
5）强化学习中，机器需要探索环境来获得样本，并且学习的目的是长期的奖赏，因此样本的标签是延迟的。
